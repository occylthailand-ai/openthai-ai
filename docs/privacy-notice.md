## 2. ข้อมูลที่เราเก็บรวบรวม

### 2.1 ข้อมูลที่คุณให้โดยตรง
- ชื่อ-นามสกุล, ชื่อบริษัท, เลขประจำตัวผู้เสียภาษี
- ที่อยู่จัดส่ง / ที่อยู่ใบกำกับภาษี
- เบอร์โทรศัพท์, อีเมล
- ข้อมูลการชำระเงิน (ผ่านช่องทางที่ได้รับการรับรอง — เราไม่เก็บเลขบัตรเครดิตโดยตรง)

### 2.2 ข้อมูลที่เกิดจากการใช้งาน
- Log การเข้าระบบ (IP address hash, เวลา, browser fingerprint)
- ข้อมูลการใช้งานฟีเจอร์ (เฉพาะเมื่อได้รับความยินยอม)
- ข้อมูลการสนทนากับ AI Agent (ประมวลผลในประเทศไทย)

### 2.3 ข้อมูลที่ได้จากบุคคลที่สาม
- ข้อมูลยืนยันตัวตนจากหน่วยงานรัฐ (เมื่อใช้บริการที่ต้องยืนยันตัวตน)
- ข้อมูล LINE UID (เมื่อผูกบัญชี LINE OA)

## 5. การโอนข้อมูลระหว่างประเทศ

ข้อมูลส่วนบุคคลของคุณประมวลผลและจัดเก็บในประเทศไทยเป็นหลัก (**Sovereign by Default**)
ในกรณีที่ต้องโอนข้อมูลออกนอกประเทศ เราดำเนินการเฉพาะเมื่อ:
- ประเทศปลายทางมีมาตรฐานคุ้มครองข้อมูลที่เพียงพอ หรือ
- มีสัญญา Standard Contractual Clauses (SCC) ที่สอดคล้องกับ PDPA

## 8. มาตรการรักษาความปลอดภัย

- **การเข้ารหัส:** AES-256-GCM สำหรับข้อมูลพักอยู่ (at-rest), TLS 1.3 สำหรับข้อมูลในการส่ง (in-transit)
- **การจัดการกุญแจ:** SoftHSM2 สำหรับ staging, Hardware HSM สำหรับ production (แผน)
- **Zero Trust:** ตรวจสอบ JWT ทุก request ไม่ไว้วางใจเครือข่ายภายใน
- **Audit Log:** บันทึกทุกการเข้าถึงข้อมูลสำคัญ พร้อม fingerprint ต้านการปลอมแปลง
- **RBAC:** แยกสิทธิ์ตามบทบาท ไม่มี root access โดยไม่มีการ review
