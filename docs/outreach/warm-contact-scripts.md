# สคริปต์ Warm Outreach — ขายแพ็กเกจบริการจับคู่ธุรกิจ (฿15,000-25,000) ให้คนที่รู้จักจริง

สำหรับเป้าหมายเงินสดระยะสั้น (แผน "ทางเลือก 1" — ตัดสินใจ 2026-07-04): ขาย**บริการ
ที่คุณลงมือทำเอง** (จับคู่คู่ค้า + การตลาด โดยมีแพลตฟอร์มเป็นเครื่องมือ) ไม่ใช่ขายตัวระบบ
ราคาและเนื้อหาแพ็กเกจอ้างอิงหน้า `/services` ที่มีอยู่จริง
(`frontend/src/pages/ServicePackagesPage.jsx`) เท่านั้น

## กติกาการใช้ (สำคัญกว่าตัวสคริปต์)

1. **ส่งเฉพาะคนที่รู้จักกันจริง** — เคยคุย เคยทำงานด้วย เคยซื้อขายกัน หรืออยู่กลุ่ม
   เดียวกันและเคยตอบโต้กันมาก่อน ห้ามส่งหารายชื่อที่ scrape มา (ถูกปฏิเสธไปแล้ว
   3 ครั้งใน `DECISIONS_LOG.md` — ทั้งเรื่อง PDPA และความน่าเชื่อถือของแบรนด์)
2. **ห้ามอ้างความสนิทที่ไม่มีจริง** — ไม่มี "ติดตามผลงานมานาน" ถ้าไม่เคยติดตามจริง
   เปิดด้วยความสัมพันธ์จริงที่มี: "เราเคยเจอกันที่..." / "พี่เคยช่วยผมเรื่อง..."
3. **ห้ามใส่สถิติ/ตัวเลขที่ตรวจสอบไม่ได้** — ไม่มี "ลูกค้าเพิ่ม 300%" ไม่มี
   "การันตียอดขาย" จุดขายของเราคือความตรงไปตรงมา (ตรงกับกรอบความจริงบนหน้า
   `/services` เอง)
4. **บอกตรงๆ ว่าเป็นโปรเจกต์ของเรา** — "ผมกำลังทำแพลตฟอร์ม/บริการนี้อยู่" ไม่ใช่
   แอบอ้างเป็นบริษัทใหญ่
5. ทุก `[placeholder]` ต้องแทนด้วยข้อมูลจริงก่อนส่ง ห้ามส่งค้าง placeholder
6. ถ้าเขาไม่ตอบ: ตามได้ **1 ครั้ง** ห่างกันอย่างน้อย 3-4 วัน แล้วหยุด —
   ความสัมพันธ์มีค่ากว่าดีลเดียว

## ลำดับคนที่ควรติดต่อก่อน (Warm ที่สุด → เย็นลง)

1. **ผู้ผลิต/affiliate ที่สมัครเข้ามาเองแล้ว** ผ่าน `/portals/*` — คนกลุ่มนี้
   ยินยอมให้ติดต่อแล้ว (PDPA consent ตอนกรอกฟอร์ม) และแสดงความสนใจเองก่อน
   ดูรายชื่อได้ใน Admin Panel แท็บ "ลูกค้า/ลีด"
2. คนที่เคยทำธุรกิจ/ค้าขายด้วยกันโดยตรง
3. เพื่อน/คนรู้จักที่ทำธุรกิจ SME, OTOP, วิสาหกิจชุมชน
4. สมาชิกกลุ่ม (LINE/Facebook) ที่เคยคุยโต้ตอบกันจริง
5. คนที่เพื่อนแนะนำให้ (ขอให้เพื่อนแนะนำ — ดูสคริปต์ขอ referral ด้านล่าง)

## สคริปต์ 3 — โทรศัพท์ (โครงบทพูด 15 นาที)

1. **เปิด (2 นาที):** ทักทายด้วยเรื่องจริงที่มีร่วมกัน → บอกตรงๆ ว่าโทรมาเรื่องงาน
   "ผมทำบริการจับคู่ธุรกิจอยู่ อยากเล่าให้ฟังเผื่อเป็นประโยชน์"
2. **ถามก่อนขาย (5 นาที):** ตอนนี้ขายทางไหนอยู่ / อยากได้คู่ค้าแบบไหน /
   ติดปัญหาอะไร — **ฟังมากกว่าพูด** ถ้าเขาไม่มีปัญหาที่เราช่วยได้จริง อย่าฝืนขาย
3. **เสนอ (5 นาที):** เลือกแพ็กเกจเดียวที่ตรงปัญหาเขาที่สุด (อย่าไล่ครบ 3 อัน)
   บอกราคาตรงๆ พร้อมสิ่งที่ได้ และสิ่งที่เรา**ไม่**สัญญา (ไม่การันตียอดขาย)
4. **ปิด (3 นาที):** "ถ้าสนใจ ผมส่งสรุปขอบเขตงานให้ดูก่อน ตกลงกันแล้วค่อยชำระ"
   → นัดวันตอบกลับที่ชัดเจน

## การรับมือคำถามที่จะเจอบ่อย

- **"แพงไหม ฿15,000-25,000?"** — เทียบกับการจ้างพนักงานขาย/การตลาด 1 เดือน
  ถูกกว่า และเป็นงานที่มีขอบเขตส่งมอบชัดเจน จ่ายครั้งเดียว ไม่ใช่รายเดือน
- **"การันตีผลไหม?"** — ตอบตรง: ไม่การันตียอดขาย เราการันตี**สิ่งที่ทำ**
  (จับคู่ที่คัดจริง + คอนเทนต์ + ติดตามผลตามแพ็กเกจ) เหตุผลที่เราไม่โม้ตัวเลข
  คือเหตุผลเดียวกับที่พี่ควรเชื่อเรา
- **"ต่างจากลงทะเบียนฟรีใน portal ยังไง?"** — ลงทะเบียนฟรีคือเข้าเครือข่าย
  รอจับคู่ตามโอกาส แพ็กเกจคือมีคนลงมือหาให้ ประสานให้ และทำการตลาดให้
  ภายในเวลาที่กำหนด
- **"ขอลดราคา"** — ลดขอบเขตงานแทนการลดราคา (เช่น Business → Starter)
  หรือแบ่งจ่าย 2 งวด (ก่อนเริ่ม/เมื่อส่งมอบ) — อย่าลดราคาเฉยๆ เพราะจะตั้งราคา
  ครั้งหน้าไม่ได้อีก

## เมื่อปิดได้แล้ว

1. สรุปขอบเขตงานเป็นลายลักษณ์อักษร (แชทก็ได้) ให้เขายืนยันก่อนรับเงิน
2. รับชำระผ่านช่องทางจริงของแพลตฟอร์ม (PromptPay ผ่านระบบ Omise ที่มีอยู่แล้ว)
   หรือโอนตรงพร้อมออกหลักฐานรับเงิน
3. บันทึกลูกค้าใน Admin Panel — lead จากหน้า `/services` เข้าระบบอัตโนมัติอยู่แล้ว
   (type `portal:service-package`)
