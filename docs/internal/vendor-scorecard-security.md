# แบบฟอร์มคัดเลือกผู้ตรวจสอบความปลอดภัย (Security Audit Vendor Scorecard)
## [INTERNAL STRICTLY CONFIDENTIAL]
**อ้างอิง:** `docs/internal/rfp-security-audit.md` | อัปเดต: สิงหาคม 2569

---

## วิธีใช้

1. ส่ง RFP ให้ผู้สนใจ 3–5 ราย
2. รับข้อเสนอ → กรอก Scorecard นี้ต่อผู้สมัคร 1 ราย/แผ่น
3. รวมคะแนน → เสนอ 2 อันดับแรกให้ Mythos พิจารณาขั้นสุดท้าย

---

## ส่วนที่ 1 — คุณสมบัติขั้นต่ำ (Pass/Fail)

ผู้สมัครที่ตอบ "ไม่" แม้แต่ข้อเดียวจะถูกตัดออกทันที

| # | เกณฑ์คุณสมบัติขั้นต่ำ | ใช่ | ไม่ใช่ |
|---|----------------------|-----|-------|
| PF-1 | มีใบรับรองวิชาชีพ OSCP, OSCE, CEH หรือเทียบเท่า ≥ 1 ใบในทีม | ☐ | ☐ |
| PF-2 | จดทะเบียนบริษัทในประเทศไทย หรือมีสาขาที่ขึ้นตรงต่อกฎหมายไทย | ☐ | ☐ |
| PF-3 | ยินยอมลงนาม NDA ก่อนรับ Source Code | ☐ | ☐ |
| PF-4 | ยืนยันทดสอบบน Staging Environment เท่านั้น (ไม่แตะ Production) | ☐ | ☐ |
| PF-5 | ส่ง Technical Report พร้อม PoC ได้ภายใน 10 วันทำการ | ☐ | ☐ |
| PF-6 | ไม่มีความขัดแย้งทางผลประโยชน์กับ OpenThai AI | ☐ | ☐ |

**ผ่านคุณสมบัติขั้นต่ำ:** ☐ ใช่ (ดำเนินการต่อ)  ☐ ไม่ใช่ (ตัดออก)
