## 1. Use Cases ต่อสายวิชาชีพ

### 🏛️ ทนายความ / นิติกร
| ทำได้ ✅ | ทำไม่ได้ ❌ |
|---|---|
| ค้นหา precedent และ case summary | ให้ความเห็นทางกฎหมายแทนทนาย |
| ร่างหนังสือ / สัญญา draft เบื้องต้น | ลงนามเอกสารกฎหมายใด ๆ |
| สรุปเอกสารยาว (คำฟ้อง, คำร้อง) | ตัดสินชี้ขาดข้อพิพาท |
| แปล/ย่อกฎหมายเป็นภาษาที่เข้าใจง่าย | เป็นที่ปรึกษาเดี่ยว (ต้องมีทนายตรวจ) |
| ค้นหาประกาศ/กฎกระทรวง ล่าสุด | อ้างตัวเลขบทลงโทษโดยไม่ตรวจ ฉบับล่าสุด |

**กรอบกฎหมาย:** พ.ร.บ. วิชาชีพกฎหมาย (ถ้ามี) + จรรยาบรรณสภาทนายความแห่งประเทศไทย

### 🏥 แพทย์ / พยาบาล / เภสัชกร
| ทำได้ ✅ | ทำไม่ได้ ❌ |
|---|---|
| สรุปงานวิจัย/systematic review เป็นภาษาไทย | วินิจฉัยโรค |
| ค้นข้อมูลยาอันตรกิริยา (Drug Interaction) | สั่งจ่ายยา |
| เตรียม patient education materials | แทนที่การประเมินทางคลินิก |
| สรุป CPG (Clinical Practice Guideline) | ตีความผล lab/imaging |
| ช่วยเขียน Discharge Summary draft | ลงนาม Medical Certificate |

**กรอบกฎหมาย:** พ.ร.บ. วิชาชีพเวชกรรม / พ.ร.บ. วิชาชีพการพยาบาล / พ.ร.บ. วิชาชีพเภสัชกรรม

### 📊 นักบัญชี / ผู้สอบบัญชี (CPA)
| ทำได้ ✅ | ทำไม่ได้ ❌ |
|---|---|
| ตรวจสอบความสมเหตุสมผลรายการบัญชี | ลงนามรับรองงบการเงิน |
| คำนวณภาษีเบื้องต้น + ตรวจคำนวณ | ยื่นแบบภาษีแทนผู้เสียภาษี |
| สรุปงบการเงินภาษาง่าย | ออกความเห็น Audit อย่างเป็นทางการ |
| ค้นหาประกาศ กรมสรรพากร / มาตรฐาน TFRS | ให้คำแนะนำภาษีโดยไม่มีนักบัญชีตรวจ |
| วิเคราะห์ variance / ratio เบื้องต้น | รับรองเอกสารทางการเงินใด ๆ |

**กรอบกฎหมาย:** พ.ร.บ. การบัญชี + มาตรฐาน TFRS (ออกโดย FAP) + ประกาศกรมสรรพากร

## 3. สถาปัตยกรรม On-Premise (บังคับ)

ข้อมูลวิชาชีพเป็น Sensitive Data ตาม PDPA — **ต้องประมวลผลในองค์กรเท่านั้น**

```
[User Browser] ──HTTPS──> [On-Prem API Gateway]
                                    │
                    ┌───────────────┤
                    │               │
             [AI Inference]   [Audit Logger]
           (On-Prem GPU/CPU)   (tamper-proof)
                    │
             [Thai LLM Model]
           (no external API call)
```

**ข้อกำหนด On-Premise:**
- ไม่มีการส่งข้อมูลออกนอก network องค์กร
- Audit log ทุก query พร้อม user ID + timestamp
- Encryption at rest (AES-256) + in transit (TLS 1.3)
