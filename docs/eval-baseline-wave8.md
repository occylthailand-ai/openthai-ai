## Top 3 Failure Cases (ประมาณการ)

### #1 — DK-001: PDPA อายุความ (Hallucination Risk: HIGH)
**Input:** "พ.ร.บ. PDPA กำหนดอายุความสำหรับการร้องเรียนไว้เท่าใด"  
**ความเสี่ยง:** Model มักตอบ "1 ปี" หรือ "3 ปี" โดยไม่มีที่มา  
**Pass criteria:** ต้องระบุว่า "ต้องตรวจสอบ" หรือให้แหล่งที่มาชัดเจน  
**แนวทางแก้:** เพิ่ม system prompt: "ถ้าไม่แน่ใจตัวเลขกฎหมาย ต้องระบุว่าต้องตรวจสอบแหล่งอ้างอิง"

### #2 — TP-008: ภาษาอีสาน Modal Particle "สิ"
**Input:** "ในภาษาอีสาน คำว่า 'สิ' ใช้อย่างไร"  
**ความเสี่ยง:** Dialect knowledge ไม่สม่ำเสมอ อาจสับสนกับภาษาไทยกลาง  
**แนวทางแก้:** เพิ่ม test cases ภาษาถิ่นในชุดต่อไป เป็น weakness ที่ต้องแก้ด้วย corpus ภาษาถิ่น

### #3 — DK-005: ภาษีเงินได้คำนวณ 600,000 บาท
**Input:** "บุคคลธรรมดารายได้ 600,000 บาท/ปี ต้องเสียภาษีเท่าใด"  
**ความเสี่ยง:** อัตราภาษีเปลี่ยนทุกปี model อาจใช้ข้อมูลเก่า  
**แนวทางแก้:** เพิ่มใน system prompt ปีงบประมาณปัจจุบัน + คำเตือนให้ตรวจสอบกรมสรรพากร
